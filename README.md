# 瀬戸内の海賊王（Pirate King of the Seto Inland Sea）

船長（仮の名前は源義経。名前は変えられる）が海賊となり、姫路港から壇ノ浦・下関を目指すブラウザ用 3D アクションゲーム。
瀬戸内海の地形・島々・港・坂・社寺・家並みを、国土地理院の地理院タイルから 3D で作っています。

`index.html` を Web サーバーで開けば遊べます（ビルド不要。`python3 -m http.server` など）。
`main` に push すると GitHub Actions（`.github/workflows/pages.yml`）が GitHub Pages に公開します（最初に一度だけ、リポジトリの Settings → Pages → Build and deployment の Source を「GitHub Actions」にしてください）。

## 遊び方

姫路港から出航し、西へ進みます。風は西へ吹いているので、西へは速く、東へは遅く進みます。
潮は満ち引きで向きが変わり、上げ潮は紀伊水道・豊後水道の両方から鞆の浦の沖へ、下げ潮はその逆へ流れます。明石海峡・鳴門海峡・来島海峡・関門海峡などの瀬戸では速く流れ、船が左右に流されます（時間は縮めています）。
財宝のある島（⚓）の岸に入ると自動で上陸し、財宝を奪ってまた船に戻ります。本州・四国・九州には上陸できません。
関門海峡に入ると壇ノ浦の決戦。平家の怨霊船団を全て沈め、下関（唐戸）に着けばゴールです。

| 操作 | 海（海賊船） | 島（小早川の戦い方） | スマホ |
| --- | --- | --- | --- |
| 移動 | `W` `S` 帆の上げ下げ／`A` `D` 舵 | `WASD`／矢印 | 画面左をなぞる |
| 主な攻撃 | `J`／左クリック：鉄砲の一斉射撃 | `J`／左クリック：刀（3 連目で回転斬り・鉄砲の弾を弾く） | 右のボタン |
| 二つ目の攻撃 | `K`／右クリック：焙烙玉（駆を使う） | `K`／右クリック：槍（駆を使う・2 人まで貫く・駆けながら突けば突撃） | 右のボタン |
| 駆（ダッシュ） | `Space`：漕ぐ | `Space`：駆ける・敵を蹴散らす | 「駆」長押し |
| 上陸・乗船 | `E` | `E`（船のそば） | 「上陸」 |
| カメラ | `Q` `E`・ホイール | `Q` `E`・ホイール | — |
| 一時停止 | `P`／`Esc` | | 「止」 |

- 島の頭目を討つとおむすび（体力回復）を落とし、配下は逃げ出します。沈めた船は兵糧樽（船体の修理）を落とします。
- 体力（島）と船体（海）のどちらかが 0 になると終わりです。港に戻ると船体を少し直します。
- 日本語と英語に対応しています（タイトル画面で切り替え。島の名前は英語ではローマ字）。

## 再現しているもの

- **地形**：瀬戸内海全域（東経 130.75〜135.5 度、北緯 33.55〜34.85 度）を国土地理院の標高タイル（DEM10B, z10）から作成。本州・四国・九州・淡路島と、無人島を含む全ての島。
- **島の名前**：地理院地図に載っている島の名前 741 を集め、無人島にも名前を付けています。標高データに無い小島 54 は海岸線から形を作りました（`tools/build-names.mjs`、`tools/build-islets.mjs`）。
- **有人島 143 島**（瀬戸内海の有人島は数え方によって約 140〜160）：`tools/islands-src.txt` の島を国土地理院の地名検索で座標に直し、標高データの陸のかたまりと結び付けて上陸できるようにしています（`data/islands.json`）。
- **上陸した島**：その場で国土地理院から次を読み込み、実寸（1 単位 = 1m）で作ります。
  - 標高（DEM5A 5m メッシュ、無い所は DEM10B）→ 坂・浜・山。坂では足が鈍ります
  - 空中写真（シームレス空中写真 z17、約 1m/画素）→ 畑・浜・道・港の見た目。写真の緑の濃い所に木を立てます
  - ベクトルタイルの建物の形 → 家並み（切妻の瓦屋根、坂の家は石垣の上）、神社（鳥居・社殿・灯籠）・寺の地図記号
- **橋**：明石海峡大橋、大鳴門橋、瀬戸大橋（下津井瀬戸大橋・櫃石島橋・岩黒島橋・与島橋・北/南備讃瀬戸大橋）、しまなみ海道（新尾道大橋・因島大橋・生口橋・多々羅大橋・大三島橋・伯方大島大橋・来島海峡大橋）、音戸大橋、周防大島大橋、関門橋。主塔の高さ・桁の高さ・形式（吊橋・斜張橋・アーチ・トラス）は実物に合わせています（`js/data.js` の `BRIDGES`）。
- **名所**：厳島神社の大鳥居・社殿・五重塔（島では鹿）、鞆の浦の常夜燈・雁木・対潮楼・弁天島、尾道の千光寺、耕三寺、大山祇神社、直島の南瓜、エンジェルロード（潮で沈む）、大久野島のうさぎ、赤間神宮の水天門、壇ノ浦古戦場、和布刈神社、友ヶ島灯台。
- **潮**：鳴門の渦潮、来島海峡、早鞆の瀬戸では船が引き込まれます。
- **海域と海賊**：大阪湾（雑賀衆）、播磨灘（家島の海賊）、備讃瀬戸（塩飽水軍）、備後灘（鞆の浦の海賊）、芸予諸島（村上水軍）、安芸灘・広島湾（毛利水軍）、伊予灘・周防灘（周防の海賊）、関門海峡（平家の怨霊）。進むほど空は夕暮れに、壇ノ浦では赤く染まります。

## 小早川から使っているもの

[孤軍奮闘小早川](https://github.com/techgymjp/kobayakawa) の戦い方（駆・刀の 3 連撃と回転斬り・弾返し・槍の 2 人貫き・駆けながらの突撃・おむすび・武将はひるまない・頭目を討つと配下が潰走）の数値をそのまま m に直して使い、効果音（`js/audio.js` の前半：鬨の声・法螺貝・太鼓・斬撃など）もそのまま使っています。
BGM は都節音階・陽音階で新しく作りました（海：尺八と琴の舟歌／海戦：太鼓と鉦／島：琴と太鼓／壇ノ浦：琵琶と法螺貝）。

## ファイル構成

- `index.html` / `style.css` — 画面と UI
- `js/main.js` — 起動・入力・場面の切り替え・HUD・結果
- `js/sea.js` — 海モード（地形・海・空・船・敵船・橋・名所・渦潮・壇ノ浦）
- `js/island.js` — 島モード（地理院タイルの読み込み・家並み・社寺・木・戦い）
- `js/models.js` — 船・武者・鳥居・社殿・五重塔・常夜燈・橋などの 3D モデル
- `js/data.js` — 橋・名所・渦潮・海域・島の言い伝え・物語
- `js/geo.js` — 緯度経度と座標の変換、標高
- `js/mvt.js` — ベクトルタイルの読み取り
- `js/audio.js` — 効果音と BGM（WebAudio）
- `js/i18n.js` — 日本語・英語
- `js/vendor/three.module.min.js` — three.js r170（MIT）
- `data/` — 瀬戸内海の標高（`dem10.png`）と有人島（`islands.json`）
- `tools/` — `data/` を作るスクリプト（`node tools/geocode.mjs` → `node tools/build-dem.mjs` → `node tools/build-islands.mjs`）
