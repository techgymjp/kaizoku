**詳しい説明**

```
あなたは海賊船の船長・源義経。姫路港を出て、瀬戸内海を西へ。
国土地理院の地形と空中写真から作った、本物の瀬戸内海と140を超える有人島を3Dで再現。
島に上陸して財宝を奪い、海賊船を沈めながら、最後の決戦の地・巌流島をめざせ。

■ 海の戦い：船首の鉄砲隊と大砲
・船首に並んだ5人の鉄砲隊が、船の向いている方へ一斉に撃つ。近いほどよく当たる
・大砲は、船首の前にいる敵の動きを読んで撃ち込み、まとめて吹き飛ばす
・敵の船には8人の船員。全員倒すと船は自爆する
・大きな安宅船は大砲を撃ってくる。船首が赤く光り、海に赤い輪が出たら舵を切ってよけろ
・西へ吹く風、満ち引きで向きの変わる潮の流れ、鳴門の渦潮。本物の海で航海する

■ 島の戦い：刀と槍で、財宝を奪え
・金色の光の柱が立つ港に入ると、自動で上陸
・刀は3回続けて回転斬り、槍は走りながら突けば一気に貫く。「全速」で駆け抜けろ
・坂道の町、段々畑、みかん畑、田んぼ、神社。島ごとに本物の地形と町並み
・平安から幕末まで、800人を超える歴史上の武将が、西へ進むほど時代を下って立ちはだかる
・一度倒した武将は二度と出てこない

■ 島を回るほど、決戦が楽になる
・財宝を奪うたびに、船の体力の上限が上がる
・素通りした島の武将は、決戦で援軍として巌流島に集まってくる
・航海で沈めなかった船も、すべて巌流島に集結。一艘残らず沈めて、宮本武蔵と佐々木小次郎の像が立つ巌流島へ

■ その他
・財宝を奪ったとき、決戦に勝ったときには花火
・海賊映画のような勇ましい音楽
・タイトルに戻ると自動で保存。「途中からはじめる」で続きから遊べる
・やられても、広告を見れば体力満タンで復活（1回の航海で3回まで）
・戦果と称号を友だちにシェア
・日本語・英語対応
・島の地形と写真を読み込むため、通信が必要です

地形・空中写真・建物：国土地理院「地理院タイル」を加工して作成
戦い方・効果音・主人公：「孤軍奮闘小早川」（テックジム）より

さあ、出航。瀬戸内の海賊王になれ！
```
